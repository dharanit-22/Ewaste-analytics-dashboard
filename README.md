♻️ Bengaluru E-Waste Analytics Dashboard
The **Bengaluru E-Waste Analytics Dashboard** is a premium, interactive web application designed for municipal corporations, environmental officers, and recycling agencies. It provides a visual and predictive toolkit to monitor electronic waste (e-waste) generation, identify infrastructure deficits, calculate precious metal recovery values, and simulate capacity growth projections.

## 🌟 Key Features
* **Interactive AI Insights & Alerts:** Real-time predictive alerts with expandable details, action triggers, and dismiss options.
* **Precious Metal Recovery Engine:** Dynamic estimates and value calculations for Gold (Au), Silver (Ag), Copper (Cu), and Palladium (Pd).
* **Forecast Simulator (2026–2031):** Multi-year growth forecasting using an interactive timeline slider.
* **Interactive Recycler Locator:** Look up authorized local recycling hubs by zone and ward.
* **Document Exporters:**
  * **Weekly PDF Report:** Instant print-ready document formatted cleanly for physical page layouts.
  * **CSV Exporter:** Easy download of the multi-year dataset using native browser Blobs.

## 🎨 Tech Stack & Design System
* **Core:** HTML5, CSS3, Vanilla ES6 JavaScript
* **Charting:** Chart.js (with Dark/Light theme support)
* **Icons:** FontAwesome Icons
* **Design:** Glassmorphism overlay panels, neon highlights, and transitions.
